# Videos - Transformación Solidaria

Esta carpeta contiene los archivos de video para la sección "Quiénes Somos".

## Archivos Requeridos:

### Video de Presentación
- **Archivo principal**: `presentacion-transformacion-solidaria.mp4`
- **Archivo alternativo**: `presentacion-transformacion-solidaria.webm` 
- **Resolución recomendada**: 1280x720 (HD) o 1920x1080 (Full HD)
- **Duración sugerida**: 2-4 minutos
- **Contenido sugerido**: 
  - Introducción a la institución
  - Historia y trayectoria
  - Testimonios de estudiantes
  - Instalaciones (si aplica)
  - Logros y reconocimientos
  - Invitación a conocer más sobre los programas

### Thumbnail del Video
- **Ubicación**: `/public/images/video-thumbnail.jpg`
- **Resolución**: 1280x720 px
- **Formato**: JPG o PNG
- **Contenido**: Imagen representativa del video (logo, instalaciones, equipo, etc.)

## Notas Técnicas:
- Los videos deben estar optimizados para web (compresión adecuada)
- Incluir subtítulos en español (archivo .vtt) para accesibilidad
- Asegurar que los archivos no excedan 50MB para mejor rendimiento
